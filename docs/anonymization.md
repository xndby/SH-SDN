# 脱敏说明

本仓库记录的是**一条真实家庭宽带线路**上的两台光猫。因此所有能指向「这条线路是哪一条」的
标识都已隐去，而**通用性知识（型号、固件行为、命令、默认凭据、区域码）全部保留**。

---

## 1. 一律隐去的（不可公开）

| 类别 | 处理 | 为什么 |
|---|---|---|
| **LOID** | 全文替换为 `XXXXXXXXXX` | 光路身份证，与宽带账号绑定。拿到它就能在另一台 ONU 上注册这条线路 |
| **设备序列号 SN** | 保留厂商前缀，后段替换为 `X`，如 `D8F507-XXXXXXXXXXXXXXXXXXXX` | 可被局端用于绑定校验；前缀是 OUI/厂商标识，不指向个人 |
| **PON / 基础 MAC** | 保留厂商前缀，后段替换，如 `D8:F5:07:XX:XX:XX` | 同上；部分局端按 MAC 绑定 |
| **Telnet 密码** | 替换为 `XXXXXXXXXXXX` | 设备级凭据。12 位长度保留，便于对照格式 |
| **WiFi SSID / PSK** | 不出现，或写作 `ChinaNet-XXXX` | 可直接定位住户 |
| **公网 IP / 宽带账号** | 不出现 | 直接可定位 |
| **备份产物** | `onu_backup/` 整体进 `.gitignore` | 内含明文 LOID / SN / MAC（`DEVICE-PARAMS.md`、`tagparam_raw_dump.txt`） |

> 判断标准很简单：**这条信息能不能单独用来「在别处把这条线路注册起来」或「定位到具体住户」**。
> 能，就隐去。

## 2. 保留的「半公开」信息

有两类信息看起来像敏感数据，但实际上是**区域内统一、且属于厂商侧设计缺陷**的东西，
隐去反而降低了文档价值。它们被保留：

### 2.1 出厂超密 / 默认凭据

| 项 | 值 | 性质 |
|---|---|---|
| 中兴 F7015TV3 超密 | `telecomadmin` / `nE7jA%5m` | 全国范围公开多年的出厂默认值；改区域码不影响它 |
| 烽火 HG5143F 管理密码 | `sdn123456` | 上海区域 SDN 设备**共用**的固定凭据，不是每机随机（`dm_addr.conf` 里的 base64 就是它） |
| SDN 认证 cookie | `20170601` | 硬编码常量，与设备、会话均无关 |

这些是**安全缺陷本身**，也是后来者复现时必须知道的输入。隐去它们，文档就失去了可用性；
保留它们，也不会泄露任何一台具体设备 —— 因为它们对同型号设备都一样。

### 2.2 区域码

| 码 | 区域 | 说明 |
|---|---|---|
| `205` | 上海 | `/etc/init.d/regioncode` 里 32 行明文映射表的一项 |
| `206` | 重庆 | 同上；本机出厂值 |

区域码是**固件内置的公开映射表**，任何拿到同版本固件的人 `cat /etc/init.d/regioncode` 都能看到。
它决定的是「复制哪份省模板」，与住户身份无关。

### 2.3 运营商侧参数

VLAN 划分（0 / 46 / 85 / 51）、DNS / NTP / SDN 控制器地址、各类 `15.192.x.x` 网段 —— 均属
上海电信的**区域性基础设施地址**，不指向个人线路，保留有助于他人对照排查。

## 3. 只想看结论？一句话

- **能定位到「你这户」的** → 已隐去（LOID / SN / MAC / Telnet 密码 / SSID / 账号 / IP）
- **能帮别人复现的** → 已保留（型号、固件、命令、超密、区域码、VLAN、运营商网段）

## 4. 本地完整版怎么留

公开仓库永远只有占位符。真实值留在**本机**，建议放在同一个 `.gitignore` 覆盖的位置：

```
# 本机私有（不入库）
onu_backup/              # 分区镜像 + DEVICE-PARAMS.md（含明文 LOID/SN/MAC）
*.local.md               # 自己的参数备忘
```

如果确实需要一份「填好真值的私人版本」，把占位符替换回来即可 —— 占位符长度刻意与真实格式对齐：

| 占位符 | 真实格式 |
|---|---|
| `XXXXXXXXXX` | LOID，10 位数字 |
| `D8F507-XXXXXXXXXXXXXXXXXXXX` | SN，`厂商前缀-20 位十六进制` |
| `D8:F5:07:XX:XX:XX` | MAC，`OUI + 3 字节` |
| `XXXXXXXXXXXX` | Telnet 密码，12 位十六进制 |

## 5. 提交前自检

```bash
# 在本仓库根目录跑，全部应该零命中

# 1) LOID：loid / PONLOID / 2180 附近出现 8 位以上连续数字
grep -rniE "(loid|2180)[^\n]{0,24}[0-9]{8,}" . --include="*.md" --include="*.py"

# 2) MAC：六组两位十六进制以冒号分隔（排除已打码的 XX 形式）
grep -rnE "([0-9A-Fa-f]{2}:){5}[0-9A-Fa-f]{2}" . --include="*.md" | grep -vi "xx:xx"

# 3) SN 后缀：16 位以上连续十六进制
grep -rnE "\b[0-9A-Fa-f]{16,}\b" . --include="*.md"

# 4) Telnet 密码：脚本里出现的 12 位十六进制字面量
grep -rnE "\b[0-9A-Fa-f]{12}\b" . --include="*.py"
```

> 写规则时别把真值当示例：自检命令本身如果贴了真实 LOID 的片段，就等于没脱敏。
> 用「结构特征」（位数、字符集、出现位置）描述，不要用值。
